# Contributing

This repository is currently a documentation and scaffolding-first project for the Valorant Visual Audio (VSA) pipeline described in README.md.

## What to expect

- The core audio pipeline files are placeholders at this stage.
- New work should keep the repository structure aligned with the README pipeline.
- Data files and trained checkpoints should remain out of version control.

## Suggested workflow

1. Create or update the relevant pipeline script in the repository root or under scripts/.
2. Keep the implementation focused on one stage of the pipeline at a time.
3. Add or update documentation when behavior changes.
4. Open a pull request with a short summary of the change and any validation steps.
